# Daily Learning & Notes

A personal knowledge repository that automatically tracks daily learning, notes, code snippets, and insights.

## 📚 About

This repository serves as a digital journal and knowledge base that grows organically through daily commits. Each day, the system automatically creates meaningful entries across different categories:

- **Learning**: New concepts, technologies, or skills learned
- **Notes**: Thoughts, observations, and reflections
- **Code Snippets**: Useful code examples and solutions
- **Quotes**: Inspiring or insightful quotes

## 📁 Structure

```
.
├── notes/          # Daily notes and reflections
├── learning/       # Learning entries and concepts
├── code-snippets/ # Code examples and solutions
├── quotes/         # Inspirational quotes
└── daily_commits.py # Automated daily commit script
```

## 📝 Content Types

### Learning Entries

Document new technologies, concepts, or skills you're exploring.

### Notes

Capture thoughts, observations, and daily reflections.

### Code Snippets

Save useful code examples, solutions, or patterns you discover.

### Quotes

Collect inspiring quotes from books, articles, or conversations.

## 🚀 Getting Started

The automation is already set up! Commits are created automatically every day.

To manually create entries:

```bash
python3 daily_commits.py
```
