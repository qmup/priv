# Simple circuit breaker

**Date:** 2026-05-14

## Description

Fail fast after a streak of errors.

## Code

```python
class CircuitBreaker:
    def __init__(self, threshold=5):
        self.threshold = threshold
        self.failures = 0
        self.open = False

    def record(self, ok):
        if ok:
            self.failures = 0
            self.open = False
        else:
            self.failures += 1
            self.open = self.failures >= self.threshold
```
