# Retry with jitter

**Date:** 2026-07-27

## Description

Backoff that avoids thundering herds.

## Code

```python
import random
import time

def retry(fn, attempts=5):
    delay = 0.2
    for i in range(attempts):
        try:
            return fn()
        except Exception:
            if i == attempts - 1:
                raise
            time.sleep(delay + random.random() * delay)
            delay *= 2
```
