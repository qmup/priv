# Debounce decorator

**Date:** 2026-01-05

## Description

Ignore rapid repeat calls during a quiet window.

## Code

```python
import time

def debounce(seconds):
    def wrapper(fn):
        last = {"t": 0}

        def inner(*args, **kwargs):
            now = time.monotonic()
            if now - last["t"] >= seconds:
                last["t"] = now
                return fn(*args, **kwargs)
        return inner
    return wrapper
```
